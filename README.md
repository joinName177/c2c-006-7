# c2c-006 · 决策后悔模拟器

Vue 3 + TypeScript + Vite 纯前端决策反思工具。支持录入 2–4 个方案、设置稳定/成长/自由/金钱权重、生成 1/5/10 年后悔指数与预演卡，并以 SVG 曲线比较“最不后悔”方向。

## 架构

- `src/core`：领域模型、输入校验、权重归一化、后悔评分、预演与安全提示
- `src/ports`：案例仓储和打印端口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、分步组件和原生 CSS

## 运行

```bash
npm install
npm run dev
npm run build
docker compose up --build
```

Docker 部署访问 `http://localhost:8106`。案例仅保存在当前浏览器。

指数是透明、确定性的本地规则：分别计算 1、5、10 年价值偏差和可逆性成本，再按 30% / 40% / 30% 合成总分。它不预测真实未来，也不替代医疗、法律或投资专业意见。

## 方案比较与口径

结果页可任选两个方案生成差距拆解：

- **按 1 / 5 / 10 年拆细**：每个时间点列出稳定、成长、自由、金钱四个价值贡献与独立的不可逆成本；展开“判断依据”可看到两端的影响值（-5 ~ +5）、本次推演的归一化权重、时间系数与可逆性。
- **差额方向固定**：所有差额恒为“对照 − 基准”，正数表示对照方案后悔分更高。“反转比较方向”只是交换两端，符号与受益方由同一纯函数精确反转，不重新挑理由。
- **细项与总分对账**：排序、差额与并列判定全部使用未舍入精确值；展示统一四舍五入（细项 0.1 分、总分整数）。每个时间点都有一行“舍入 / 截断余量”，使细项展示值之和加余量精确等于展示差额。
- **抵消不省略**：贡献按绝对差额排序，绝对值 ≥ 0.5 分的项全部列出；正负两侧最大的对抗项强制成对呈现，摘要同时给出毛额与对消后的净额。
- **小差异不被整数掩盖**：整数总分相同但精确差 ≥ 0.05 时明确提示“整数口径正在掩盖差异”；精确差 < 0.05 判实质并列，不给胜者。
- **绑定分析版本**：每次推演带唯一编号、时间戳和输入签名。输入修改后比较标记为过期，重新推演后续绑到新分析；删除比较中的方案会立即结束比较。保存案例时比较对象与其所绑定的分析快照一并保存。
